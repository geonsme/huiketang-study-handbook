# 组合诊断、再平衡与决策复盘

依据：E11–E19、E26、E32、E33、E35、E36、E48、E55、E58–E60、E63。模板是本 skill 的操作化补充。

## 组合体检：不按基金数量算分散

取得持仓金额、成本/买入时点（仅复盘需要）、份额、目标角色、锁定/到账约束、数据日。先统一市值、币种与评价范围。

| 暴露层 | 检查什么 |
| --- | --- |
| 资产与地区 | 股、债、现金、商品、房产及跨境，区分经济风险与上市地 |
| 股票因子 | 大小盘、行业、成长/价值、集中持仓和指数成分重复 |
| 固收 | 久期、信用质量、主体、杠杆、转债/权益交叉风险 |
| 策略 | 同一交易周期、趋势、对冲工具、容量和流动性依赖 |
| 管理人与渠道 | 相同团队、关联底层、估值/运营/托管与渠道集中 |
| 家庭整体 | 雇主、工资奖金、房产、经营收入与金融资产的共同冲击 |

穿透不全就列已知/未知比例和披露日期，不擅自还原当前全持仓。相似命名既不能证明重复，不同名称也不能证明分散。

有足够对齐的总回报数据时才算相关性，说明样本与滚动变化，避免把危机前的相关性当永久常数。相关性低不等于无共同尾部风险。

## 给每项资产一个工作

要求持有人能回答：为什么持有、服务哪笔钱、替代是什么、在哪种情景中会令人失望。

将持仓归入 `承担明确角色 / 疑似重复 / 不符合资金用途 / 证据不足`，而不是按短期收益从高到低排去留。

识别三种不同问题：

- **资产选错：** 家庭需要流动性，却拿了长锁定高波产品。
- **工具选错：** 需要某种暴露，但当前工具成本高或偏离太大。
- **预期错配：** 合同与行为一致，却被当成另一个产品使用。

这三种问题对应不同动作，不一律归咎管理人。

## 再平衡规则

目标结构先由家庭目标和风险预算决定，不把节目随手举例的比例当标准答案。E17、E19、E48。

给用户写简版投资约定：

```text
评价范围、支出币种和资产快照日期：
生活/现金流底线与明确用款：
各类资产或策略的目标区间及理由：
常规复核频率与偏离触发条件：
可优先使用的新增现金流/到期资金：
需要遵守的费用、税费、锁定与到账限制：
家庭变化/策略变化/重大风险事件的例外处理：
由谁决策，执行前核对什么：
```

阈值和频率可以与用户商定，但标明是本次约定而非董艺婷通用规则。先比较用新增现金流纠偏与卖出重买的成本。资金用途改变或实质风险出现时，不应因尚未到半年/一年就停止处理。

再平衡是风险纪律，不保证每次提高收益；市场持续单边时可能落后。不能为了凑权重买入已不符合要求的产品。

## 持有、减配与换基

先比较“目标需要什么”与“当前产品提供什么”。E63。

| 原因 | 合理下一步 | 不足以单独证明什么 |
| --- | --- | --- |
| 短期跑输 | 对齐基准、风格、费用、经理期与行情，检查预期偏差 | 不能直接证明策略失效 |
| 单纯涨多/盈利多 | 检查组合偏离、未来用款与估值，而不只看成本价 | 不能自动证明应全部止盈 |
| 家庭目标或期限改变 | 优先安排流动性与风险预算，评估退出成本 | 不代表原基金质量差 |
| 理念与行为持续冲突 | 核查同期说明、合同和暴露，再比较替代 | 一次持仓变化不等于欺骗 |
| 团队/容量/策略改变 | 新旧阶段分开评估，必要时降低依赖 | 名气与历史成绩不能替新团队背书 |
| 已核实的违约/重大运营风险 | 核查可用的赎回、沟通、留证与专业求助路径 | 不能用“再等等回本”忽略问题 |

比较替换时的全部成本：赎回/申购、业绩报酬结算、税费、价差、资金空档、锁定期及新产品证据强弱。沉没成本不是继续持有理由，但实际交易成本仍需计算。

可以分步迁移，不机械全部清仓；也不为回避短期不适而频繁换风格。不能把“越跌越便宜”当作任意基金补仓逻辑，先分资产价格、策略失效和信用/合规损害。

## 行为复盘

E18、E32、E55 强调记录当时理由与后果。把决策质量和结果分开：

- 好过程可能遇到坏结果，坏过程也可能碰巧赚钱。
- 只知道“我早就看好”不够，要有当时可见的证据和风险预算。
- 市场波动、风格逆风、管理人失误、实施成本和投资者交易行为分别归因。
- 不用事后挑选最优资产作为事前合理基准。

最小决策日志：

| 字段 | 记录内容 |
| --- | --- |
| 决定与日期 | 做什么、涉及多少钱、服务哪个目标 |
| 当时已知 | 数据日期、来源、尚未确认的信息 |
| 投资理由 | 收益机制、为什么选它而非简单替代 |
| 反证 | 什么事实出现就重新判断，何时检查 |
| 不利情景 | 金额损失、现金流、是否被迫卖出 |
| 情绪/执行 | 当时的压力、追涨/回本冲动、费用与可成交性 |
| 复盘 | 预期与事实的差异，改进一项流程，而非重写原理由 |

若用户说“跌了不能卖，不卖就不亏”，先区分未实现损益与真实经济损失、继续持有依据和可承受后果；不羞辱用户，也不为其找理由硬扛。

## 输出

优先给最重要的 1–3 个问题及其处理顺序，必要时附持仓角色表和条件动作表。说明本次结论由哪些现有材料支持，哪些穿透数据仍未知。无需生成大量用户不会使用的表格。
