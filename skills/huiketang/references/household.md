# 家庭理财：钱的用途先于产品

适用：资产配置、买房、养老、教育、收入不稳、家庭分工、跨币种支出、是否有条件增加风险。

核心依据：E04、E05、E26–E33、E50、E53、E58–E60、E65。下面的问卷、压力测试和计算器是本 skill 的实施补充，不是节目里的统一标准。

## 最少需要知道什么

先用用户已有信息，缺少且会影响结论时只追问最重要的 1–3 项。

| 维度 | 关键输入 |
| --- | --- |
| 用钱 | 目标金额、最早/最晚用款时间、能否推迟、可否缩水、支出币种 |
| 现金流 | 税后可靠收入、必要与可选支出、债务还本付息、保费及赡养义务 |
| 资产负债 | 可投资金融资产、房产/经营资产、全部负债、流动性和权属 |
| 风险能力 | 收入中断、资产下跌、赎回受限时会怎样；最大可承受金额损失 |
| 风险意愿 | 过去回撤中的实际行为、失眠阈值、夫妻/家庭成员意见 |
| 实施条件 | 投资经验、时间精力、地区/税务居民身份、账户与产品限制 |

不需要姓名、身份证、完整账户或密码。只收集任务所需资料，不把真实家庭数据写入 skill 示例，不向网络搜索发送个人明细。

“需要很高回报”不是“能够承受很高风险”。目标不可行时优先讨论储蓄、支出、期限、目标规模与可靠收入，而不是用加杠杆补上收益缺口。

## 资金分层与资产分工是两个维度

节目讨论过先拿出保障/救急的钱，再区分日常开销、应急储备和真正长期不用的钱；养老本身仍是明确目标。E29、E30。这不是固定比例的“四个账户产品推荐”。

实操按下表逐笔登记，避免日常预算、应急和年度大额支出重复占用同一笔现金：

| 资金用途 | 要回答的问题 | 约束 |
| --- | --- | --- |
| 日常与保障 | 靠什么收入支付日常费用、保费与必要债务？ | 现金到达时间和支出时间匹配；不能把保单保额当流动资产 |
| 应急储备 | 哪些收入中断/突发支出要覆盖，覆盖多长？ | 可及时、低损耗使用；规模由具体情景决定，不统一套月数 |
| 明确目标 | 学费、首付、养老等何时需要多少，最低额是多少？ | 分期限和刚性程度，长期目标也不是任意损失预算 |
| 真正风险资本 | 扣除前述承诺后，剩余资金亏损会影响什么？ | 结合客观能力和意愿设上限，不因“长期”自动满仓权益 |

资产分工则是现金流支持、稳定/防守、长期增长、机会性配置等。**不要把一个用途层与一种产品一一绑定。** 一只债券基金未必满足近期刚性支出，房产也未必能随时兑现，分红不是额外无成本的现金。

## 财务底图

先给资产负债和现金流摘要，再讨论配置：

- 金融资产与总资产分开，房产估值不等于可投资现金，养老金和保单按实际可用性登记。
- 债务记利率、重定价、期限、抵押和月供；不把全部房贷视为股票杠杆，也不忽略高成本短债。
- 现金流按时间列，避免将年度保费既摊入月支出又计入一次性缺口。
- 工资、奖金、雇主股权与投资组合共同暴露于同一行业时合并看待，不把未来工资按面值当现金资产。E58。
- 夫妻共同/独立账户、决定权限和应急可用性明确，但不把节目家庭案例中的 AA 制或房产比例套给用户。E26。

## 从目标到方案

1. 把确定支出的最低额和时间锁定，识别不能承担市场回撤的部分。
2. 做至少一个对家庭有意义的不利情景：收入减少、回撤、赎回延期或大额支出，可组合发生。
3. 由能承受的金额后果倒推风险预算。区分组合损失预算与某一只产品的历史最大回撤。
4. 再构造资产/策略方案，比较收益机制、费用、流动性和管理成本，至少有一个较简单的可行对照。
5. 给出实施顺序和重评条件，不强制购买复杂产品。用户条件足够时可以给金额/比例区间，但说明是假设方案，计算和加总须可复核。

若没有证据支持年化回报，用情景敏感性而不是精确“最佳比例”。概率、收益率和通胀假设不得伪装成预测。

## 压力测试与生活检验

情景由用户、历史事件或清楚标明的压力假设提供。历史最大回撤不是未来最坏情形。

| 冲击 | 检查结果 |
| --- | --- |
| 收入中断/下降 | 每月净缺口、可用储备覆盖月数、还贷/保费是否可持续 |
| 权益与雇主股权一起下跌 | 总损失金额、家庭目标缺口、是否迫使低位卖出 |
| 多只基金同时回撤 | 共同因子及组合损失，不按独立事件相乘 |
| 私募锁定/暂停赎回 | 支出到期前实际能拿到的钱，而非账面资产 |
| 汇率不利 | 生活/学费币种下的资产与负债，不只看外币收益 |
| 支出增加 | 医疗、照护、家庭变动等预算空间；保险保障与可变现价值分开 |

输出“能否维持目标和生活选择”，不要只报一个波动率。

## 特定问题

### 买房、还贷与投资

比较现金流、融资成本、提前还款约定、交易成本和流动性选项，利率/税费需核验当前规则。不能用高风险基金的历史收益直接减确定贷款利率来证明应借钱投资。

### 养老与财富自由

从生活支出下限、可靠养老金/收入和期限出发，压力测试通胀、寿命与提取顺序风险。长期平均回报不意味着每年固定回报；不能把 6%–8%、某个提取率或 GDP/CPI 当普适安全线。E28、E34–E36、E55、E61。

### 保险与保障

识别保障缺口、保费支付能力、责任、除外条款和退保成本。产品与税务/法律问题查适用地区最新材料，必要时请具资质人员确认。不要在未看合同前劝退保，也不把保障型保险当投资账户比较收益。

### 海外配置与汇率

以支出币种统一计算。若外币资产收益为 `r_asset`，每单位外币兑换本币的价格变化为 `r_fx`：

```text
本币收益 = (1 + r_asset) * (1 + r_fx) - 1
```

定义汇率报价方向，已经是本币净值时不要重复折算。E65 对应的节目减法算例不能照抄：20% 外币收益叠加外币贬值 12%，复合结果为 5.6%，不是 8%，尚未计未包含的费用。这是算术校正，不是对该段历史行情的验证。

## 计算器

`scripts/portfolio_check.mjs` 做可复核的**长仓金融资产快照**，不优化组合、不估计回报、不抓取行情、不交易，也不把房贷、空头或衍生品简化成多头资产。

运行：

```bash
node scripts/portfolio_check.mjs --input /absolute/path/household.json
node scripts/portfolio_check.mjs --help
```

输入所有金额使用同一币种的基本单位，例如人民币使用“元”而不是“万元”，收益/权重用小数；示例是合成数据，不是推荐配置：

```json
{
  "currency": "CNY",
  "as_of": "2026-10-24",
  "monthly_essential_outflow": 15000,
  "stressed_monthly_income": 5000,
  "reserve_months": 12,
  "committed_outflows": 20000,
  "loss_budget": 150000,
  "holdings": [
    {"name": "cash", "amount": 200000, "liquid_reserve": true, "target_weight": 0.2},
    {"name": "equity", "amount": 500000, "liquid_reserve": false, "target_weight": 0.5},
    {"name": "bond", "amount": 300000, "liquid_reserve": false, "target_weight": 0.3}
  ],
  "scenarios": [
    {
      "name": "income_and_market_stress",
      "returns": {"cash": 0, "equity": -0.3, "bond": -0.05}
    }
  ]
}
```

字段规则：

- `as_of` 是用户数据日期，不是脚本运行日；`currency` 是说明标签，脚本不兑换汇率。
- `monthly_essential_outflow` 包括必要生活、债务还本付息等；`stressed_monthly_income` 是同一情景下仍可靠到账的收入，不能用正常工资替代。
- `reserve_months` 是用户指定期限，必须正数；`committed_outflows` 是该期限内**尚未计入月预算**的一次性承诺。月预算、储备和承诺金额不要重复。
- `liquid_reserve: true` 只用于已确认及时可用、无质押/锁定且未另有用途的储备。它由输入者判断，脚本不会把货币基金或债券基金自动认证为现金。
- 目标权重要么全部省略，要么每项提供且合计为 1；由用户或经确认的方案提供，脚本不推荐权重。
- 每个情景必须给出每项资产的回报，连现金也要显式写 `0`。不能把未知回报默认为零。长仓损失最低为 `-1`，输入中不支持杠杆。
- `scenarios` 可省略或为空，此时只计算静态资金与权重，并明确尚未做市场压力测试。
- 赎回延期等可用每个情景的可选 `unavailable_reserves: ["cash"]` 从该情景可用储备中剔除，未损失的资产仍计入组合市值。只允许引用本来标记为储备的资产。
- `loss_budget` 可省略；有值时输出情景净损失是否超过用户预算。它不是产品止损线。

计算口径：

```text
月度净缺口 = max(必要月支出 - 压力情景下可靠月收入, 0)
所需储备 = 月度净缺口 * 覆盖月数 + 未重复计入的一次性承诺
储备缺口 = max(所需储备 - 合格可用储备, 0)
覆盖月数 = max(合格可用储备 - 一次性承诺, 0) / 月度净缺口
资产权重 = 该资产市值 / 本次输入金融资产总额
情景盈亏 = sum(资产市值 * 该资产情景回报)
权重偏离 = 当前权重 - 目标权重
```

月度净缺口为零时覆盖月数输出 `null` 并给出原因，不输出无穷大或“财务自由”。初始/压力后储备均单独核算；一次性承诺不足仍报告缺口。

**解释限制：** 市场回报按一次性冲击计算，组合市值没有再扣未来支出；现金流测试是并列的预算检查，不能把两项相加当预测净资产。收入、时间和支出路径有变化时分情景运行或另做逐月预算。该工具不计算税费、申赎成本、通胀、保险责任或多币种净额；输入回报必须注明已包含哪些成本。持仓市值可包含自身嵌入杠杆的基金，但其情景收益必须由外部压力分析给出，本工具并不模拟内部杠杆或追保。
