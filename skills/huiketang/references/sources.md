## 编号、时间与归属

`n` 是仓库文件号，不一定等于 Vol 编号。特殊篇、预告与重编内容必须保留各自性质。

- 例如 `transcripts/102.json` 对应 Vol.101。
- `n=112` 的目录标签是“特别篇”，但标题明确为 Vol 111；索引保存两个字段，不把它叫成 Vol.112。
- `n=47` 只包含约三分钟付费节目的试听，不能推断付费正文。
- 合集、串台和二次剪辑有重叠，不能当成多次独立证据。
- 时间戳为 ASR 段首，常约一分钟粒度且相邻片段有重叠，不声称是精确音频时间。

## 证据库怎么用

[evidence.json](evidence.json) 每条保存：

- 稳定 ID、文件号、零基段号、主题和归属。
- `claim`：本 skill 的概括，不是逐字引文。
- `boundary`：场景、限制、转写或归属提醒。
- `quote`：原样保留的 ASR 子串，不暗中润色成更好听的金句。
- 附近上下文、标题、发布日期、节目链接、段首时间、本地文本行号和原 JSON 的 SHA-256。

本地文本行号只用于定位；没有匹配时为 `null`，不要伪造行号。SHA-256 只能证明文件版本，不能证明音频、转写和发言都绝对正确。

```bash
node scripts/corpus.mjs stats
node scripts/corpus.mjs evidence E03 E04 E53
node scripts/corpus.mjs search "宏观 变量" --root /path/to/huiketang-study-handbook --limit 5
node scripts/corpus.mjs episode --episode 112 --chunk 24 --radius 1 --root /path/to/huiketang-study-handbook
```

搜索以空白分词、字面 OR 匹配，再按命中词数排序，不是语义检索。指定 `--episode` 可减少噪声。完整索引见 [corpus-index.json](corpus-index.json)。

原文检索范围是该索引覆盖的快照，新增节目须更新索引后才纳入。读取原文时核对 SHA-256；文件内容已变而索引未更新会报错，应检查差异后更新，不能把新原文配上旧引用。

找不到原目录时，脚本明确返回“仅附带摘录”，不能声称搜索了全部 353.8 万字符。若要引用摘录外的观点，要找到原文或诚实说明证据不足。

## 不固化历史结论

优先保留可复用机制，而不是删除其历史立场或把它永久化：

- 她会做市场和风格判断，也会战术调整，不能包装成“永不预测、永不择时”。
- 90%/10% 是家庭案例中的假设，不是家庭标准答案。E31。
- 3–5 年的资金稳定假设不是必然回本期限。E50。
- 节目中的合格投资者数字须按当前法规核实；“500万元”等是经验性的适配讨论，不是法定门槛。E53。
- 曾讨论的 6%–8% 或 GDP/CPI 参照不能变成保证收益、所有家庭的目标或可投资基准。E55、E61。
- 节目机构优选的私募样本不代表全部可投资私募，需保留样本与幸存者偏差。E21、E45。
- 保留董艺婷的 FOF 从业视角，不能把经验优势写成完全中立或经实证证明适合所有人。
- 低相关、长期风险补偿、危机 Alpha、红利低波、历史最大回撤都不是未来保证。

发生前后观点差异时，列原日期、适用对象和变量变化，区分条件变化与真实修正；不强行拼成永不矛盾的体系。

## 转写与算术校正

原 ASR 可能把“指增”写成“指针”、把“市场中性”写成“市场中心”等。概括可用规范术语，但引号内保留原样或明确标注校正，避免伪造逐字引文。

E65 所在段以“外币资产涨 20%、外币相对本币跌 12%”简化相减为 8%。本 skill 使用复合关系：

```text
(1 + 20%) * (1 - 12%) - 1 = 5.6%
```

这是在给定假设下的算术校正，未验证节目所述历史年份的实际指数和汇率表现。不要为了忠于表达而照抄错误，也不要把补充计算反说成她的原话。

## 更新协议

当用户明确要求更新 skill 语料时：

1. 对原目录运行 `node scripts/corpus.mjs verify --root /path/to/corpus`，先识别新增/变更，不能先覆盖快照掩盖差异。
2. 阅读新增原文及相邻语境，确定说话人、发布日期、例子边界与旧观点关系。
3. 编辑证据条目的 `claim/boundary/quote`，追加新 ID；不要为凑数量重新编号或复制重编内容作为独立证据。
4. 对涉及的模型/专题做必要修改，将新观点与原有适用条件关联；统计覆盖范围如有变化同时更新本文与主文件。
5. `refresh` 只重建摘录元数据和全目录索引，不会自动理解新内容；随后 `verify` 并运行测试。

```bash
node scripts/corpus.mjs refresh --root /path/to/corpus
node scripts/corpus.mjs verify --root /path/to/corpus
node --test tests/*.test.mjs
```

此流程不修改手册正文、不转写音频、不发布网站、不提交 Git，也不自动把更新后的源文件同步到用户安装目录。安装副本的更新须在用户要求范围内完成。
