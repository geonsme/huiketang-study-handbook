# 公私募基金：质量、性价比、个人适配

适用：选基、基金比较、私募路演材料审阅、管理人投资思想分析、是否继续持有或替换。

核心依据：E03、E14–E16、E20–E25、E37–E46、E51–E54、E56、E62–E64。本文件的尽调维度、计算口径和报告结构是操作化补充，不是董艺婷发布的官方评级体系。

## 先给三项独立结论

| 判断 | 真正要回答的问题 |
| --- | --- |
| 质量 | 是否诚实履行约定，能力与组织能否支持所承诺的服务，风险是否可理解、可验证 |
| 性价比 | 扣除适用成本后，与可投资的简单替代相比，额外服务和收益来源是否值得付费 |
| 适配 | 这项风险、期限、最低金额和服务，是否正是这个家庭缺少且承受得起的 |

“产品质量较好，但不适合作为你明年首付款的载体”可以同时成立。质量不由短期排名单独决定；适配也不代表未来不亏。

每项判断标记为 `证据较支持 / 有条件支持 / 证据不足 / 出现实质负面证据`，同时给理由。可按维度陈列，不默认打分、加权排名或声称精确胜率。

## 第一道关：先确认是什么、是否可以核实

确认全称、产品代码/登记信息、具体份额、管理人、策略、币种、成立日期、份额开放条件、数据截至日。公司同名、同一经理不同产品、A/C 份额、母子基金不能混为一谈。

“私募”先分**证券投资基金**与**股权/创投基金**，后者不适合套用流动证券的日净值评价方法。

材料按用途取最小集合：

| 要判断什么 | 优先需要的材料 |
| --- | --- |
| 是否合规且主体真实 | 适用地区监管/协会公开记录、合同主体、募集和托管账户核对 |
| 买的是什么服务 | 有效合同/招募说明书、投资范围、基准、仓位/对冲权限、风险揭示 |
| 赚的是什么钱 | 连续净值及分红/费用口径、定期报告、持仓/暴露、基准与策略说明 |
| 管理人有无能力 | 同一策略可比记录、经理任职时间、同期解释、团队与流程资料 |
| 能否退出、成本多少 | 份额条款、锁定期、开放日、通知期限、到账周期、费率和提成条款 |
| 是否适合家庭 | 资金用途、投资期限、已有暴露、流动性和损失预算 |

**材料缺失不等于造假。** 私募信息不公开时请用户提供可合法分享的脱敏材料；不能凭销售截图认定优质，也不能凭无搜索结果指控违法。发现确凿主体不一致、违约或不当资金路径等，写清证据、出处与影响，先处理核验和风险，不用高收益抵消问题。

当前合规状态、适当性要求、基金经理与条款必须实时查询。登记备案不是投资能力、持续合规或资金安全的背书；不帮助拼单、拆分或伪造资格。相关一手补充来源见 [来源与边界](sources.md#一手外部补充)。

## 第二道关：工具属性与委托属性

依据 E20、E38、E54、E56。

- **工具：** 是否准确、低成本、可持续地提供约定暴露？行业基金下跌不等于失职，指数基金跟踪准确也不等于此时价格便宜。
- **委托：** 用户把哪些决策交给管理人？主动选股、仓位调整、对冲还是跨策略配置？评价是否对应其实际权限和承诺。
- **混合：** 指数增强通常有基准 Beta 与主动部分，FOF 可能有配置和选基两层服务。把职责拆开，避免拿产品做它不能做的事。

问一句：“若只需要这一项风险暴露，用简单、透明的工具能否实现？若付更多钱，买到哪项可验证的额外服务？”

## 业绩校准：先保证在比同一件事

1. 使用同日期区间、币种、份额和分红再投资口径；区分基金成立以来与经理任职期。不要把经理前任业绩算给现任。
2. 基金使用可验证的复权总回报或明确计算分红，不把累计净值直接当可复投资产价格；净值口径包含的费用不再扣一次。
3. 基准先看合同，再检查能否解释实际风险。股票/行业/久期/信用/地域差异明显时，宽基跑输比较不能独立证明能力差；主动偏离也需解释。
4. 指增优先校准包含分红的全收益基准，注明税前/税后及可投资性；价格指数遗漏的分红不是自动 Alpha。E14。
5. 区分实际运行、回测、模拟、机构优选样本与完整可投资样本。检查幸存者、回填、选起点、规模变化和清盘产品遗漏。E21、E45。
6. 能取得连续序列时比较滚动窗口、上下行环境、回撤与修复、回撤期暴露。低频/滞后估值可能低估风险；短历史不外推完整周期能力。

计算时声明定义：

```text
同期间简单超额（百分点） = R_fund - R_benchmark
相对财富增长 = (1 + R_fund) / (1 + R_benchmark) - 1
最大回撤 = max_t(1 - 净值_t / 截至t的净值高点)
```

这两种“超额”口径不同；都不自动等于风险调整后的 Alpha。回归 Alpha 还依赖因子、频率、样本与误差；不能用残差直接证明能力。E15。

年化、夏普、信息比率、相关性仅在日期、频率和计算口径清楚时计算；列窗口与观测数。只有收益/最大回撤两个数，无法还原真实波动、回撤路径或相关性。没有数据就留空，不用经验数补齐。

## 收益与风险归因

依 E16 分三层：**大类资产仓位 → 行业/风格 → 个股或具体交易**。再检查费用、交易与对冲成本。

| 表现来源 | 要区分的可能性 |
| --- | --- |
| 高收益 | 市场 Beta、行业/大小盘暴露、选股、择时、杠杆、偶然收益 |
| 低回撤 | 真正风险控制、低仓位、对冲、估值平滑、样本太短或尚未经历压力 |
| 稳定超额 | 多环境能力、拥挤的风格因子、隐藏尾部风险、基准不匹配 |
| 共同亏损 | 同一因子、流动性撤离、基差/对冲、赎回、市场结构，而不只是哪种算法 |

公开持仓有时点和覆盖限制。无法穿透的部分标记“未知”，说明可验证到哪一层；不能声称还原日频持仓或取得董艺婷机构的自有模型。E12、E16、E51、E52。

## 管理人投资思想：把口号变成可验证主张

先研究产品行为，再看人的解释。E03。允许理念随证据更新，但要求事前/同期说明；不要因一段访谈好听就打高分。

做一张“理念画像”，按任务挑重点：

| 维度 | 要提炼的具体内容 |
| --- | --- |
| 认知与能力圈 | 相信市场哪里有可重复机会？哪些领域明确不做？ |
| 收益来源 | 估值修复、盈利成长、趋势、风险补偿、统计定价、套利等，谁在付出成本？ |
| 组合构造 | 单标的/行业集中度、仓位、持有期限、分散方式、杠杆和对冲 |
| 风险定义 | 波动、永久损失、相对跑输、流动性或客户目标失败，哪些最不能接受？ |
| 决策与认错 | 买入、加仓、卖出、模型迭代由什么事实触发？如何区分噪声与失效？ |
| 组织与利益 | 关键人依赖、研究与风控权限、激励、容量管理、规模与客户收益的冲突 |
| 客户承诺 | 适合什么资金，在哪些市场会落后，是否能坦诚解释不舒服的时期？ |

把每项主张转成可证伪链条：

| 主张 | 应观察到的行为 | 可查资料 | 何种发现构成冲突 |
| --- | --- | --- | --- |
| 长期基本面投资 | 持有期、买卖理由与盈利/估值逻辑一致 | 定期报告、持仓变化、同期信件 | 无说明地频繁追逐热门主题 |
| 稳健绝对收益 | 风险预算、仓位与对冲规则实际执行 | 压力期暴露、净值和风控记录 | 收益主要来自高 Beta/杠杆，却只宣传稳健 |
| 指数增强 | 基准暴露与偏离边界透明 | 合同、跟踪误差、行业与市值偏离 | 另一类 Beta 主导却称为稳定 Alpha |
| 量化持续迭代 | 有模型监控、验证、切换和容量流程 | 实盘/回测分离、模型失效复盘 | 只讲算法先进，不解释失效、成本与控制 |
| 客户利益优先 | 规模控制、费用和解释行为支持 | 限募、费率条款、沟通记录 | 超容量扩募或利益冲突长期不披露 |

冲突先核对时间、权限和资料完整性，不由一次持仓变化直接判“说谎”。不同流派不预设高低：价值、成长、趋势、量化均有适用条件和难受阶段，重点是**自洽、可执行、行为一致、成本合理、能否适合用户**。

有价值的尽调追问包括：

- 过去一次最难受的回撤来自什么，与事前风险预算差在哪里？
- 什么结果会使你承认原策略失效？多久发现，谁有权停用，如何防止过拟合？
- 当前规模离容量还有多远？扩募后交易冲击与机会稀释如何观察？
- 哪些收益是市场/风格给的，哪些才是团队的贡献？
- 当客户可能无法持有时，你如何调整产品设计、预期和沟通？
- 风控约定与投资负责人意见冲突时，实际谁能执行？

这是需要证据回答的问题，不是要求管理人披露全部商业机密。

## 组织、合规与执行

E23–E25、E37、E39、E62、E64 强调组织成熟度、容量和真正执行。

- 核对团队稳定性、策略责任人、关键人离职预案、交易/估值/风控分工与独立约束。
- 核查产品净值、估值来源、托管/外包关系和关联交易。通过独立获取的官方渠道交叉确认，转发邮件、徽章或邮箱域名都不足以单独鉴真。
- 观察压力时合同是否履行；止损/预警线按具体约定理解，不保证能按该价成交，也不拿“最终涨回来”证明控制有效。
- 规模既可能提升研发能力，也可能侵蚀交易容量，不机械选择最小或最大机构。
- 对投诉、处罚、诉讼等区分传闻、正式事实、涉事主体、发生时间与整改状态，不传播未经证实的指控。

## 不同产品的重点

### 公募主动基金

核实经理任职期、团队、风格、资产/行业边界、换手与容量；将报告中的理念与实际仓位对应。考察不同市场下是否忠于约定、风险是否在预期内，而不是只比较最近一年排名。

同策略比较份额费率和预计持有期；A/C 份额不预设哪个永远便宜，按当前申赎费、销售服务费、优惠与持有期限算。

### 指数基金、ETF 与跨境 ETF

先研究指数规则、成分集中、调整机制和目标暴露，再研究基金的跟踪差异/误差、规模、流动性、费用、价差与清盘风险。

场内价格不等于净值。溢折价、买卖价差、停牌、跨境交易时差/额度及 IOPV 局限需要单独核验；盘中估算值不是保证可成交的公允价格。低费率不能抵消过高溢价。监管与招募说明书补充见 [来源](sources.md#一手外部补充)。

### 私募股票多头与指数增强

除通用维度外，核对最低股票仓位、投资范围、集中度、杠杆、衍生品权限和风格漂移边界。指增拆分基准收益与主动部分，检查微盘/行业风险是否被当作 Alpha。E14、E37–E39、E50、E51。

“三至五年不用”不是回本保证。购买资格与经济适配分开，最低认购金额可能令家庭过于集中；不要固化节目中的“500万元”等经验数字为法定或普适门槛。E53。

### 市场中性

核对多头真实暴露、对冲标的和比例、基差、交易/融资成本、保证金、流动性和尾部风险。名称“中性”不等于存款，也不保证与股票零相关。E40–E42。

比较预期收益时将贡献统一到产品净资产口径：多头超额贡献、空头/对冲损益、现金收益与各类未包含成本分开。期货名义本金、保证金和基金资产不是同一个分母。没有这些数据就不硬套节目简化算式。

### CTA 与多策略

区分趋势/截面/套利等方法、交易周期、品种、风险预算与迭代。趋势反复、跳空、流动性枯竭和风控去杠杆可能伤害表现。危机 Alpha 是条件性的，不是每次股灾必赚。E45、E46。

查看完整可获得样本和实盘历史，警惕幸存者偏差；多策略数量不是分散程度，检查是否同向依赖趋势、波动或流动性。

### 固收、固收+、红利

债券看久期、信用、杠杆、集中、流动性和赎回匹配。固收+穿透股票和转债部分；红利/低波仍是权益。不能因为名字稳健就放入应急储备。E43、E44。

### FOF

拆开配置、选基、监控、再平衡与客户服务价值，比较简单可实施组合。穿透底层重叠与流动性错配，核对关联基金、费用层级、提成和赎回条件。底层净值已计入的管理费不要再扣一次。E11、E54、E56。

“专业优选私募样本优于公募”不能推导为普通人买私募一定更好。保留董艺婷作为 FOF 从业者的经验与可能偏向。E21。

### 私募股权/创投

这是范围扩展，语料证据不足以提炼董艺婷完整的 PE/VC 框架。使用通用尽调补充并明确边界：认缴/实缴、后续缴款义务、存续期及延长、退出路径、估值、项目集中、关联交易、分配瀑布、费用与 carry、关键人条款。

区分已实现与账面回报，核对 IRR、DPI、TVPI 的现金流和估值口径；IRR 可能受现金流时点和融资影响。低频估值不能直接与每日交易基金比波动/夏普；无法承受锁定和追加出资的资金不适合。法律条款需要按地区实时核验，必要时由专业人士复核。

## 费用与性价比

列出收费对象、基数、频率、期限、是否已入净值，而不是只加几个费率：

| 成本 | 特别检查 |
| --- | --- |
| 管理/托管/服务费 | 份额差异、净值内计提、最低收费与费用豁免 |
| 申购/赎回/交易 | 持有期限阶梯、渠道优惠、价差、冲击成本 |
| 业绩报酬 | 高水位、门槛、计提/结算时点、投资者份额路径、是否重置 |
| 对冲/融资 | 名义规模、基差、利息、保证金机会成本及已计入的损益 |
| FOF 多层成本 | 底层与上层分开列示，防止重复扣除净值中已有费用 |
| 税费/汇率 | 账户、地区与币种，不能用未经核实的通用税率 |

比较用户可能实际拿到的结果，保留持有路径影响。费用高不是自动差，低也不是自动好；额外收费对应的服务必须能描述、能验证。

## 报告模板

按问题裁剪，不要求每次填满。

```text
对象与截至日：
当前判断：质量 / 性价比 / 对该用户的适配 / 证据充分度
它在组合里的角色及简单替代：
管理人思想画像：收益来源、能力圈、风险定义、认错机制
理念与行为核验：主张 -> 行为 -> 证据 -> 仍未解释的冲突
表现拆解：基准与口径、Beta/风格/Alpha、压力期、全部成本
组织与条款：关键人、容量、风控、锁定与退出
最重要的支持证据 / 反证 / 未知项：
持有、候选替换或暂不投入的条件与成本：
下一步需要的最少材料、重评触发条件：
节目依据与当前产品资料分别列：
```

不能完成尽调时，明确哪项结论还能成立、哪项暂不能下。例如“最低认购会造成集中，可以先判断不适配；但缺少合同和可比净值，不能判断它本身是否优质”。
